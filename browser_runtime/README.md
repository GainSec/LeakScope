# LeakScope browser controller

Internal Playwright/Chromium service for the fetch worker. Django proxies its controls; do not publish port9227, CDP or the X server. Requests require `Authorization: Bearer <token>` loaded from `BROWSER_CONTROL_TOKEN_FILE`. The browser state lives in a new temporary context per capture/session. There is no cookie import/export or shared profile.

The container wrapper starts Xvfb, the controller and the existing Celery command. It stops the worker if the controller/display exits. `BROWSER_CHROMIUM_PATH` defaults to `/usr/bin/chromium`; `BROWSER_CONTROL_HOST` to `0.0.0.0`; `BROWSER_CONTROL_PORT` to9227. The Compose file only overrides the fetch entrypoint. Other uses of the capture image retain its original entrypoint.

`POST /capture` accepts `url`, trusted PSL-derived `site_domain`, `profile` (`strict` or `web_page`), `wait_seconds` (0–10), `timeout_seconds` (10–60), and `full_page` (boolean). A PNG and JSON diagnostics are returned as base64 artifacts. PNG output never proves visual completeness. The diagnostics distinguish verification challenges, HTTP errors, restrictions and unassessed appearance.

Strict confines traffic and navigation to the selected hostname/port. Web page allows public HTTP(S) dependencies on80/443; top-level navigation remains on the selected site, including canonical redirects under its registrable domain. An explicitly selected private/nonstandard endpoint remains usable, but that does not permit dependencies on other private hosts. DNS is bounded and pinned; mixed public/private answers fail closed for dependencies. Chromium's loopback proxy bypass is disabled. Browser requests and proxy traffic are bounded separately, including tunneled TLS bytes.

Limits: 350 browser requests,32MiB network traffic,512KiB plaintext HTTP request body,12MiB PNG,9000px full-page height,1280×800 viewport. A capture has a maximum60-second lifetime. Readiness waits for DOM and fonts, then a bounded settling period; it does not wait indefinitely for trackers or streaming requests. Software WebGL is enabled for shader-driven pages. Third-party dependencies run normal page JavaScript; profiles are capture policy, not a complete hostile-code sandbox.

`POST /sessions` opens one headed, target-bound manual session for at most10minutes. `GET /sessions/<uuid>` reports status; `/frame.png` returns a viewport image. `POST /input` supports bounded clicks, scroll, text and a small key allowlist. `/capture` produces normal capture artifacts, and `/close` destroys the browser/proxy. No arbitrary navigation, evaluation, file upload, downloads, OS key combinations, credential automation or CAPTCHA solver is exposed. Console diagnostics contain type/location, without message text or session input.

Run `npm ci --ignore-scripts && npm test`. Set `BROWSER_CHROMIUM_PATH` to system Chrome/Chromium. Tests use only loopback fixtures; `BROWSER_TEST_HEADED=1 DISPLAY=:99` exercises headed sessions under Xvfb. They verify actual PNG generation and a WebGL readPixels fixture, expiry, authentication, body limits, destination policies and diagnostics redaction. npm versions/tarball integrity and the Node image digest are pinned; Debian packages use the existing fixed snapshot.
