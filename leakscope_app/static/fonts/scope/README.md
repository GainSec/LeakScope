# Workspace typefaces

Served locally so the workbench makes no third-party font requests.

| File | Family | Licence | Source |
|---|---|---|---|
| `SofiaSans-latin-wght.woff2` | Sofia Sans (variable weight, Latin) | SIL Open Font License 1.1 | https://github.com/lettersoup/Sofia-Sans |
| `SofiaSansExtraCondensed-latin-wght.woff2` | Sofia Sans Extra Condensed (variable weight, Latin) | SIL Open Font License 1.1 | https://github.com/lettersoup/Sofia-Sans |
| `B612Mono-latin-400.woff2`, `B612Mono-latin-700.woff2` | B612 Mono | SIL Open Font License 1.1 | https://github.com/polarsys/b612 |

The WOFF2 subsets were taken from the Fontsource distribution of each family on 2026-11-11.
Sofia Sans carries interface text, its Extra Condensed cut carries headings and large figures,
and B612 Mono (drawn for aircraft cockpit displays) carries addresses, ports and hashes.
