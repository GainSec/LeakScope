# Evidence image typefaces

Used only by `evidence_render.py` to draw evidence images, so the output is the
same in every container and no font is fetched at run time.

| File | Family | Licence | Source |
|---|---|---|---|
| `B612-Regular.ttf`, `B612-Bold.ttf` | B612 | SIL Open Font License 1.1 (`OFL-B612.txt`) | https://github.com/polarsys/b612 |
| `IBMPlexMono-Regular.ttf`, `IBMPlexMono-Bold.ttf` | IBM Plex Mono | SIL Open Font License 1.1 (`OFL-IBMPlexMono.txt`) | https://github.com/IBM/plex |

Copied from the `google/fonts` repository on 2026-11-12. B612 carries labels; IBM Plex
Mono carries addresses, response text and hex, where every character must be unambiguous.
